# 本轮优化交付（2026-09-05）

本记录描述当前实现，旧 optimization_analysis.md 中的四关分析仅保留作历史参考。

## 行为改进

- 传送门按角色冷却；双人同时进入可以一起传送。到达后须离开出口再进入，避免站着被传回；冷却中的重新进入会在等待结束后重试。
- 门切换目标时取消上一段动画，用物理帧驱动门位移。
- 宝石显式防止重复领取；压力板和出口主动检查角色存活状态，杠杆清理失效对象。
- 平台通过碰撞移动携带角色和箱子，起跳者不继续被拖动；仍保留原往返路线和速度。
- Esc 暂停世界和计时，支持继续、重玩、返回菜单；在暂停菜单改键或开关音效。
- 双手柄按设备 0/1 分别映射火娃/水娃；键盘改键防止重复占用，设置持久保存。
- 压力板、门、杠杆显示通道标记；靠近杠杆显示当前键位；受控电梯显示等待供电或运行。
- 合成跳跃、拾取、机关、死亡、通关音效，缓存波形并限制为 8 个播放声部。
- 成绩分别保存最短时间、红蓝收集最高数、最少死亡和单次全收集标记。存档读取检查数值类型、范围，保存失败输出警告。
- 缓存关卡数据及 TileSet；HUD 只有时间每帧更新，收集和死亡数由事件更新；关卡生成器同步缓存模板。

## 验证

- Godot 4.7.2 六关冒烟测试：errors=0，含真实平台载客、压力板、杠杆、门联调。
- 动作能力：跳高 107 px、跳远 199 px、上浮 146 px，保持原设计能力。
- 关卡校验器自检通过，六关均无校验问题；校验通过不等于完整双人路线试玩。
- tools/regression.tscn：19 项断言通过，覆盖双人传送、防反弹、返回传送、平台载两人和箱子、跳离、顶头碰撞、门快速切换、纪录保存读取、暂停与恢复、改键、手柄输入隔离、宝石防重复、死亡清理压力板。
- 使用 OpenGL 实际渲染暂停菜单并检查截图，已修正居中和遮罩布局。
- 测试将 APPDATA 指向临时目录，避免覆盖玩家进度。

运行回归测试（PowerShell；将 Godot 路径替换为本机路径）：

```powershell
$env:APPDATA = Join-Path $env:TEMP 'Fireboy-optimization-tests'
godot --headless --path . res://tools/regression.tscn
godot --headless --path . -- --smoke
```

带渲染运行回归场景并追加 `-- --ui-check`，会将暂停截图保存到系统临时目录 Fireboy-pause.png。
