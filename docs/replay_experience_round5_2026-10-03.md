# 第五轮：重玩体验与机关定位

日期：2026-10-03。基线为已合并的 master `2795e27efcb153c13649659b48b00b4b444fc840`，基线 tree `0dc8fb0e4d3edf02149a4155a1c44c469837abd4`。本轮独立本地分支：`polish/replay-experience-2026-10-03`。

## 玩家能看到什么

1. **结算页的历史比较**：写入本局前先取得独立的旧纪录快照。历史最快、全宝最快分别比较，显示本局快/慢多少；没有旧纪录时明确标成首次记录。未全收集的快局不参与全宝最快比较。旧星级被旧版迁移清除时显示“首次按当前规则评星”，不会杜撰一个历史零星。
2. **可选挑战**：“无死亡”要求本次从进入关卡到通关，两名玩家的死亡次数合计为零；“无箱复位”要求同一完整局所有木箱复位事件合计为零。两项可在不同局分别获得，重玩后保留已获记录。没有额外处罚、不阻挡通关、不要求全宝石。三星仍只看全宝石和原时间门槛。R 或暂停菜单重玩开启新一局，计数重新开始。
3. **机关提示**：目标门/受控平台短暂显示“编号 · 门开启/门关闭/平台通电/平台停住”。门的提示留在门洞，平台的提示跟随平台。保留原有编号与线路；不拉镜头，不再用总闸全屏暖光代替定位。最多同时八项，持续 1.4 秒，重复事件合并而不无限延长；暂停冻结持续时间，场景切换清理。
4. **减少动态**：机关提示保持静态，只到期消失；既有平台能量带停止呼吸变化。“精简特效”同时省略目标轮廓，文字状态仍保留。平台的实际运行照旧。
5. **选关焦点**：通过容器布局完成通知重新同步焦点和可见区域，不依赖固定等待两帧。满成绩菜单默认第一关时从顶部开始；返回末关时末关完整可见。锁定卡片不再进入 Tab 焦点；鼠标手动滚动不会被强行拉回。

## 存档与规则边界

- 本轮没有更改地形、物理参数、机关规则、控制映射、三星门槛、评分版本或关卡内容修订号。
- 保留既有解锁和当前关卡修订下的最快、全宝最快、宝石、星级。沿用既有的分关修订隔离，旧几何修订的记录不与新关混算。
- 新挑战字段有独立版本。旧存档缺少字段保持“未记录”，不把未记录的死亡或复位数当作 0，也不会在升级时自动授予挑战。
- 两项挑战独立取“曾达成”；未完成关卡、烟雾测试和路线回放不写玩家成绩。
- 不合法的新挑战版本或载荷仅丢弃不可信的挑战元数据，保留普通成绩和其他有效关卡。验证过数组、字典、布尔、字符串、小数版本以及缺失/非整数计数。
- 已有箱子复位 +3 秒、死亡等待计时等规则完全保留。未增加新处罚。

## 验证结果

最终验证汇总见 `qa/round5/verification-summary.json`，完整日志与回放证据在同目录。

### 引擎与平台

- Linux；Godot `4.6.3.stable.official.7d41c59c4` 与 `4.7.stable.official.5b4e0cb0f`
- 两版引擎都运行完整默认检查入口，包括资源导入、静态关卡检查、既有回归、合作/恢复反例、十关冒烟及十关原始按键回放
- 第五轮定向无头检查：记录/存档 99 项，真实场景切换 19 项，菜单 241 项，机关反馈 82 项，每版合计 441 项
- 在真实图形窗口运行同一组检查并截图，每版 452 项检查（含截图保存检查）；不是仅无头检查。渲染为 Linux Mesa llvmpipe 软件 OpenGL；VSync 不受该环境支持的警告不代表游戏脚本错误。全新导入时曾先报告字体缓存未生成，标准入口自动执行第二次导入后通过；原始日志保留了这次重检
- Godot 4.7 对全部十关另做原始按键带图形回放：全部全宝石三星，零死亡、零箱复位。完成帧数、最终位置、计时、宝石、星级与第四轮基线逐项比较

### 覆盖的易错流程

- 首次通关、重复更快/更慢、接近相同时间、未全收集快局、无旧记录、旧存档迁移、坏挑战字段、分关修订、重复完成调用
- Esc 暂停/恢复，暂停里重玩/返回，R 重玩，通关后暂停、跳跃进入下一关、末关返回菜单；由真实场景入口与输入/按钮信号切换
- 十关各自作为当前关卡的初始焦点；满记录、旧记录、锁定关卡、键盘方向键/Tab/Shift-Tab、缩放和早退/重建
- 实际杠杆输入及压力板进出、机关反复切换、相同事件轰炸、暂停中修改减少动态/精简特效、被删除目标、连续十关重建与订阅清理

## 明确没有验证的部分

Windows、实体手柄、音频实际听感、低端 GPU 性能以及新的真人双人合作试玩均未实测。自动回放证明已有路线仍可行，不证明所有可能操作绝无软锁。静态校验保留第三/第四轮已有的三条非阻断警告，未借本轮改变关卡来消除它们。

这次修复的是可复现的菜单初始滚动/焦点问题。之前用户遇到的菜单全空白已经恢复，根因尚不明确；本轮不声称找出或修复了那次空白的根因。

## 使用与交付

这是独立完整源码项目包，不含预编译 Windows 程序。解压后用 Godot 4.6.3 或 4.7 打开 `project.godot`，等待导入后 F5。不要把 `tools/` 下的测试场景作为日常游戏入口。

运行检查：`python tools/run_checks.py --godot /path/to/godot`。测试入口自动使用隔离的临时存档目录；直接跑需要写档的测试场景时还会检查隔离标识，避免污染玩家进度。

本轮仅本地实施、验证和交付，没有推送、合并或部署。
