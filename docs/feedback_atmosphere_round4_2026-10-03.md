# 第四轮：角色反馈与关卡氛围

基于已试玩通过的第三轮 `c1b2cc2`。本轮仅优化表现层：关卡布局、角色运动参数、碰撞判定、机关规则、宝石位置与三星目标均保留。

## 看得见、听得清的变化

- 火娃起跳有轻火星，水娃有水滴；落地按冲击强度给局部环纹与短音效，不加镜头抖动。
- 推箱时身体轻微前倾，箱底有间隔受控的擦地细屑和轻响；不会把移动速度或碰撞体跟着压扁。
- 宝石拾取有同色菱形余光，死亡与重生有短暂元素散点和圆环，仍沿用原有复活时长。
- 十关分别采用树根入口、哨台、回廊、时序厅、高井、星象档案室、庭院、双塔、维修厅与投递中庭背景；统一暗色建筑语言，原有火、水、毒颜色保持鲜明。
- Esc 暂停中新增“减少动态”和“精简特效”，会保存偏好。减少动态同时照顾正在播放的死亡、拾取、拒绝和结算形变；切换偏好不改变碰撞和动画结束回调。

## 开销与稳定性

每关动作特效使用一个批绘节点，最多 96 个粒子、12 个环；精简模式最多 24 个粒子。场景退出即释放，静止时停止处理。环境只增加两个无碰撞节点、12 个微尘，12 Hz 更新；减少动态冻结微尘，精简特效移除微尘和细纹。音效缓存约 90 KB、最多 8 声道，重复触发限流，死亡/通关不会被推箱轻响打断。

## 验证

Godot 4.7 与 4.6.3 的完整检查入口均通过；最后一轮减少动态改动也在两版本复测通过。十关全部零死亡、零箱复位、全宝石三星，过关帧数和终点坐标与第三轮一致。

见 `qa/round4/` 中的日志、原始输入回放证据和截图。新增视觉 34 项、音效 92 项、环境 141 项自动检查；另做十关原始全宝石回放、完整既有回归与合作/恢复反例，以及 Godot 4.7 图形窗口检查。截图中的动作来自实际回放；死亡截图为独立诊断场景。

十关原始按键、过关帧数、最终位置、宝石数和三星结果与第三轮逐项对照；回放不修改角色位置、速度、机关或计分。

## 使用

解压后用 Godot 4.7 stable 或 4.6.3 stable 打开 `project.godot`，等待导入后 F5。完整检查：`python tools/run_checks.py --godot /path/to/godot`。本包为完整源码，不含 Godot 二进制、导入缓存、个人存档或独立可执行程序。

验证平台为 Linux。Windows、实体手柄、低端设备 GPU 帧率和音频实际听感未实测；音频仅完成生成波形、峰值/声道及生命周期验证。原录制路线证明可行，不代替真人双人试玩。
