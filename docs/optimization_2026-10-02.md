# 2026-10-02 可玩性与界面优化

基线：`master`，提交 `047c3ad`。本地分支：`optimize/playability-2026-10-02`。

## 已复现的问题与修改

- **菜单超出画面**：原单列十关菜单把帮助第二行及退出按钮推出 720p 视口。改为双列、可滚动关卡卡片；操作帮助和退出按钮固定留在布局内，长纪录也不会撑出屏幕
- **键盘进入菜单需先鼠标点击**：给当前关卡初始焦点；焦点移动到下方关卡时列表自动滚动。菜单显示解锁/星星进度，并从实际改键设置生成操作提示
- **双人镜头裁切**：第 8 关初始镜头只框住火娃；第 9 关大距离分离受 0.7 最小缩放限制，角色身体被裁切。初始化即框住两人，必要时突破缩放下限；普通跟随仍平滑。失效目标安全清理
- **木箱误推**：玩家同时按左右时自身方向抵消，木箱却仍移动；站在箱顶、中心稍微偏离时也可能产生侧推。改为一致的左右输入抵消，并要求真实侧面垂直重叠
- **结算面板可读性**：加宽面板，将失误另起一行，检查所有结果标签都在面板范围内
- **暂停重绑状态**：退出暂停时清理未完成改键，避免重新打开后残留捕获状态
- **测试可移植性**：新增跨平台检查入口。测试保护校验 Godot 的实际用户数据目录，避免 Linux 上仅改 APPDATA 却仍写入真实进度

未改动运动参数、关卡几何、解谜逻辑、三星门槛、存档版本或美术资源。本轮交付使用独立优化分支，未改动默认分支或部署。
