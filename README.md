# 森林冰火人 Fireboy & Watergirl

本地双人合作解谜平台游戏，共 10 关。火娃使用 A / D 移动、W 跳跃、S 交互；水娃使用方向键移动、上键跳跃、下键交互。R 重玩，Esc 暂停和改键。支持两只手柄的输入映射。

## 启动

1. 使用 **Godot 4.6.3 stable** 打开 `project.godot`，等资源导入完成
2. 按 F5 运行。也可执行 `godot --path .`
3. 两人到达各自出口后过关。红宝石归火娃，蓝宝石归水娃

支持和回归验证的版本统一为 Godot **4.6.3**（Linux）。本包是完整源码工程，未附独立可执行程序。Windows、实体手柄、音频实际听感尚未实测。

## 第二轮改进

- 双人同向推箱保持正常速度，对向推箱互相抵消；站在箱子上不会误触侧推
- 木箱落入任意液体或丢出地图后，会回到本关原位；计时继续并加时 3 秒。原位有角色/物体时等待，玩家让开即可；不会移动角色或回滚已收集宝石
- 死因提示立即优先显示；杠杆线路编号和开关状态常驻，靠近时显示当前交互键
- 压力板、双钥匙板、门和受控平台使用对应线路编号

## 自动检查

需要 Python 3.9+ 和 Godot 4.6.3，无需额外 Python 包：

```
python tools/run_checks.py --godot /path/to/godot
```

若 Godot 已在 PATH 中，运行 `python tools/run_checks.py` 即可。Windows 请传 Godot 的 `_console.exe` 路径。测试使用临时用户数据目录，避免污染玩家纪录；请不要用真实存档目录绕过测试保护。

检查包含资源导入、关卡静态校验、224 项回归断言、十关冒烟和十关完整全宝石按键回放。`--skip-smoke` 只跳过冒烟，`--skip-routes` 只跳过完整路线回放。原有四条木箱临近液体的静态警告仍保留，不用删除警告来替代动态恢复检查。

十关按键回放通过真实角色物理和机关，途中不修改位置、速度、宝石、计时或机关信号。它证明所记录的路线可行，不代表真人双人试玩、全路线无软锁或难度已充分平衡。
