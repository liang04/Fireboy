# 森林冰火人 Fireboy & Watergirl

Godot 4.6.3 的本地双人合作解谜平台游戏，共 10 关。火娃用 A / D 移动、W 跳跃、S 交互；水娃用方向键移动、上键跳跃、下键交互。R 重玩，Esc 暂停和改键。支持两只手柄的输入映射。

## 启动

用 **Godot 4.6.3 stable** 打开 `project.godot`，等待资源导入后按 F5；也可运行 `godot --path .`。两人进入各自出口后过关。红宝石归火娃，蓝宝石归水娃。

本包为完整源码工程，已在 Linux 验证，未附独立可执行程序。Windows、实体手柄和音频实际听感尚未实测。

## 十关合作改造

关卡现包含哨台运箱、上下两轮职责交换、箱子替人守板、中层换乘、空间传送接应、无液体货物护送、双塔远程接力、元素维修和合力投递。第 3 关有可选合作宝库，第 7 关保留低压力的安全路线。第 10 关误落可独立返回，已投递箱子被误推到墙边也不会使出口重新锁死。

既有土狼时间、跳跃缓冲、同向/反向合作推箱和相机保护保留。木箱仅在落液体或出界时复位，加时 3 秒；普通下落不撤销。机关线路、杠杆状态和传送配对编号可见。

## 自动检查

需要 Python 3.9+ 和 Godot 4.6.3，无需额外 Python 包：

```sh
python tools/run_checks.py --godot /path/to/godot
```

Godot 已在 PATH 时可运行 `python tools/run_checks.py`。Windows 需传 `_console.exe` 路径。测试使用隔离的临时存档目录。

包含资源导入、静态校验、229 项常规回归断言、新合作/恢复反例、十关冒烟与十关全宝石按键回放。`--skip-smoke`、`--skip-routes` 仅供局部诊断；交付前应跑默认完整入口。

十关原始回放全部通过，零死亡、零箱复位。它证明已记录路线可行，不替代真人双人试玩，也不保证所有可能操作都无软锁。新三星时间以真实回放加沟通余量确定，内容与评分修订已更新，保留解锁进度。
