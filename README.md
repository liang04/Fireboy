# 森林冰火人 Fireboy & Watergirl

Godot 4.7 的本地双人合作解谜平台游戏，共 10 关。火娃用 A / D 移动、W 跳跃、S 交互；水娃用方向键移动、上键跳跃、下键交互。R 重玩，Esc 暂停和改键。支持两只手柄的输入映射。

## 启动

用 **Godot 4.7 stable（4.7.x）** 打开 `project.godot`，等待资源导入后按 F5；命令行首次运行先执行 `godot --headless --editor --import --path . --quit`，再执行 `godot --path .`。两人进入各自出口后过关。红宝石归火娃，蓝宝石归水娃。

本包为完整源码工程，已在 Linux 验证，未附独立可执行程序。Windows、实体手柄和音频实际听感尚未实测。

## 本轮：七关合作推广

在第 3 / 4 / 8 关样板基础上完成另外七关：第 1 关短双向接应，第 2 关同箱两用与回程捷径，第 5 关先送人或先运箱的货梯接力，第 6 关任选顺序的两条固定传送支路，第 7 关无危险短主路与可选合作观景，第 9 关交叉维修与可逆屋顶接应，第 10 关两段延时投递。

第 3 / 4 / 8 关数据、修订号和既有控制器 / 原始按键回放保持不变。保留全部解锁及这三关有效纪录；另外七关旧布局的成绩和挑战需在新布局重新记录。玩法和隔离试玩方法见下文。

想直接体验任意关且不改正式进度：`python tools/play_prototypes.py --godot /path/to/godot --level 5`，关卡参数支持 **1–10**。需要 Python 3.9+ 和 Godot 4.7（4.7.x）；显式启动器使用临时独立存档，关闭窗口结束，默认 F5 仍为正常游戏。

## 第六轮：结算、暂停与存档保护

修复最后宝石与出口同帧触发时漏算宝石/星级的问题。切出窗口自动暂停，切回后手动继续；暂停前和菜单操作产生的残留移动、跳跃输入不会带回游戏。改键支持取消和恢复默认，损坏配置会修复，保存失败有提示。进度采用临时文件和备份保护，保留旧存档的解锁与有效成绩。详见 [第六轮说明与验证](docs/session_polish_2026-10-05.md)。

## 第五轮：重玩体验

通关后分别对比本局与**通关前**的历史最快、全宝最快和最高星级；慢成绩不会覆盖纪录。新增“无死亡 / 无箱复位”两项可选挑战，按双人整局计数，独立累计，不影响三星。旧存档未记录的挑战显示“待记录”，保留解锁与同修订成绩。

触发机关时，对应门或平台在原地短暂标示编号和状态；“减少动态”保留静态提示。主菜单按布局生命周期同步焦点，锁定关卡跳过键盘焦点。详见 [第五轮说明与验证](docs/replay_experience_round5_2026-10-03.md)。

## 第四轮：角色反馈与关卡氛围

新增元素化起跳/落地反馈、推箱姿态与擦地声、拾取/死亡余光，以及十关不同的暗色建筑背景。Esc 暂停里可开启“减少动态”和“精简特效”。本轮沿用第三轮的全部关卡与规则，详见 [第四轮说明与验证](docs/feedback_atmosphere_round4_2026-10-03.md)。

## 十关合作改造

十关以互相接应、职责交换、同箱两用、货梯运送、固定传送支路、观景绕路、可逆桥路、交叉维修和分段投递串联。第 3 关合作宝库保留，第 7 关可直接走平地主路；第 10 关误落可独立返回，已投递箱子被误推到井壁也不会使出口重新锁死。

既有土狼时间、跳跃缓冲、同向/反向合作推箱和相机保护保留。木箱仅在落液体或出界时复位，加时 3 秒；普通下落不撤销。机关线路、杠杆状态和传送配对编号可见。

## 自动检查

需要 Python 3.9+ 和 Godot 4.7（4.7.x），无需额外 Python 包：

```sh
python tools/run_checks.py --godot /path/to/godot
```

Godot 已在 PATH 时可运行 `python tools/run_checks.py`。Windows 需传 `_console.exe` 路径。测试使用隔离的临时存档目录。

包含资源导入、静态校验、原有常规回归、第四轮视觉/环境/音效断言，记录/流程/菜单/机关定向断言，以及第六轮暂停输入、改键故障与存档恢复回归、新合作/恢复反例、十关冒烟与十关全宝石按键回放。`--skip-smoke`、`--skip-routes` 仅供局部诊断；交付前应跑默认完整入口。

版本基准、CI 与新交付统一为 4.7；4.6.3 的旧报告保留为历史验证，不再作为当前运行建议。详见 [4.7 迁移与启动验证](docs/godot47_migration_2026-10-05.md)。
